FAQs for SysReptor Cloud ​

These FAQs are for SysReptor Cloud (hosted by Syslifters for organizations).

If you write HTB, OffSec, or other exam reports on labs.sysre.pt, use the exam report FAQs instead. Self-hosted Docker installs are covered in the self-hosted FAQs.

What is SysReptor Cloud compared to self-hosted SysReptor and labs.sysre.pt?

There are three common ways to use SysReptor:

  • Self-hosted: you install SysReptor with Docker on your own server. Self-hosted can be SysReptor Community (free) or SysReptor Professional (paid). See Installation, pricing and self-hosted FAQs.
  • SysReptor Cloud: Syslifters hosts SysReptor Professional for your organization (paid). See pricing.
  • SysReptor Labs: the free exam-reporting service at labs.sysre.pt hosted in the SysReptor Cloud for students writing certification and exam reports. See the exam report FAQs.

The public playground is a demo installation hosted in the SysReptor Cloud.

Is SysReptor Cloud free?

SysReptor Cloud is a paid hosted offering. See pricing.

SysReptor Labs at labs.sysre.pt for HTB/OffSec students is free; that is a non-commercial service.

Where is SysReptor Cloud hosted?

SysReptor Cloud currently runs in Germany on physical servers at Hetzner Online GmbH. We operate a self-managed Kubernetes cluster there on physical servers.
We guarantee that if new sites are added in the future, their location will be within the European Union (EU).

What data privacy laws apply?

Personal data in Cloud is processed under the GDPR. The Cloud contract is governed by Austrian law.

Can I have a signed DPA (AVV)?

Yes. Please contact us.

Does any Cloud customer data leave the EU/EEA?

No.

Is data encrypted in transit and at rest?

Yes. Data in transit is encrypted with HTTPS. At rest, all data is stored on an encrypted ZFS partition. In addition, every Cloud installation has its own encryption key for database and file/asset encryption. See Data Encryption at Rest.

Are Cloud tenants isolated from each other?

Yes. Each customer runs in a dedicated Kubernetes namespace with network separation. Each installation uses its own encryption keys.

PDF rendering pods are shared, but each pod is disposed after one use so rendering jobs cannot interfere with another customer. See Architecture.

Does SysReptor send report contents to third parties, e.g., for spell check or AI?

No. Spell check runs inside your Cloud installation (LanguageTool). Report content is sent to an LLM only if you configure an AI provider in settings.

Do you use my reports to train AI models?

No.

Can I use my own domain name for hosting?

Yes. Please contact us.

Can I require SSO (OIDC) and disable password login?

Yes. Superusers can enable OIDC SSO and disable username/password login in Settings → Authentication Settings (LOCAL_USER_AUTH_ENABLED=false). See SSO configuration.
You can disable local user authentication for the entire installation, or on a per-user basis.

Can I install plugins on SysReptor Cloud?

Yes. Official plugins that ship with SysReptor can be enabled in settings.

Custom plugins are only supported in self-hosted SysReptor, not in the cloud version.

Can Cloud users use the reptor CLI?

Yes. Create an API token in your user profile and configure reptor with your Cloud URL. See the reptor CLI documentation.

How do I reset my password on SysReptor Cloud?

Administrators with superuser or user manager permissions can reset user passwords in the Users UI. See the full steps.

If your cloud installation has the Forgot Password functionality enabled, you can use it to receive an email for setting a new password. You will still need your second authentication factor, if configured for your user account to successfully authenticate.

Students on SysReptor Labs can reset their password online.

Can I create backups of a SysReptor Cloud instance?

Yes. You can create a backup via web interface with your SysReptor installation's BACKUP_KEY and you must have superuser permissions. Please contact us to receive your BACKUP_KEY.

You can always export individual projects as .tar.gz from the projects list. This is not a full instance backup.

Where are backups stored?

On our own servers in Austria. Each backup is encrypted with a dedicated symmetric key. That key is encrypted with an asymmetric key. Private keys for recovering the symmetric encryption keys are stored on hardware tokens with PIN protection.

How long are backups stored?
  • Daily backups: 21 days
  • Weekly backups: 35 days
  • Monthly backups: 365 days
Can you delete my instance and confirm it?

Yes. Please contact us. We can delete your Cloud instance and confirm the deletion.

Can I migrate from SysReptor Cloud to a self-hosted SysReptor?

Yes, you can create a backup and restore it on a self-hosted SysReptor installation.

You can also move project data by exporting projects from Cloud (projects list → export .tar.gz) and importing them on a self-hosted instance.

Can I migrate from a self-hosted SysReptor to SysReptor Cloud?

Yes, you can create a backup and contact us to restore it on a SysReptor Cloud installation.

You can also move project data by exporting projects from self-hosted (projects list → export .tar.gz) and importing them on Cloud.

Is there a track record for SysReptor Cloud's availability?

Yes. See the SysReptor Cloud status page.

What is the maintenance window?

Wednesdays and Saturdays, 08:00–11:00 GMT.

Planned maintenance is also announced on the SysReptor Cloud status page. You can subscribe there for updates.

Further questions?

Need help or have questions? Get support and connect with us and the SysReptor community.
